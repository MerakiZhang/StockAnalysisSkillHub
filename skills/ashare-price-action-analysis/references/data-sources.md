# 行情数据源与快照纪律

## 允许的数据源

只使用 AkShare 的新浪和腾讯接口：

- 新浪股票日线：`stock_zh_a_daily`
- 新浪股票 60 分钟线：`stock_zh_a_minute`
- 腾讯股票日线：`stock_zh_a_hist_tx`
- 新浪指数日线：`stock_zh_index_daily`
- 腾讯指数日线：`stock_zh_index_daily_tx`

股票统一使用前复权 `qfq`；指数不做复权，元数据记为 `none`。不得使用东财、Baostock、Tushare、搜索工具、金融 MCP 或其他来源补行情。前复权产生的小数位不代表实际报价最小变动单位；A 股股票计划价使用 0.01 元最小变动单位。

## 周期

- `1d`：默认新浪，可选腾讯主源；另一来源可作为整条日线备用。
- `1h`：新浪 60 分钟线。
- `4h`：按原规则将四根 60 分钟线合成一根。

分钟线不通过腾讯拼接。单次分析快照只能使用一个来源，不得把新浪和腾讯的复权序列混拼。

## 交叉核验

日线默认对另一来源做只读交叉核验：

- 最近五根同时间 K 线比较收盘价和成交量。
- 差异只写入来源元数据和最终提示。
- 核验结果不得覆盖主源快照。
- 核验失败不自动污染已取得的有效主源数据。

## 已收盘 K 线

- K1 是最新已收盘 K 线，K0 表示未收盘棒，不进入分析窗口。
- 默认分析 100 根，并额外获取指标预热数据。
- EMA20、ATR14 和程序几何特征由本地代码计算。
- 数据不足或前置闸门失败时停止，不编造 K 线、指标或 Agent 响应。

## 网络与依赖

需要 Python 3.11+ 及 `requirements.txt` 中的依赖，并能访问新浪、腾讯行情接口。依赖由使用者准备，本 Skill 不自动安装。

本机或其他 Agent 的 Python 路径不属于 Skill 配置。使用能够导入所需依赖的解释器运行 `scripts/analyze.py` 即可。
