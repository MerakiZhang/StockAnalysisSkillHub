# 上涨通道：识别与顺势策略

## 适用条件

用于阶段二已确认或候选的上涨通道，且 `direction=bullish` 或合规 AIL。若主状态实际为 `trending_tr`，本文件只提供方向与结构参考，区间位置规则优先。

## 识别

上涨通道由交替出现的 HH 与 HL 构成，价格大致运行在两条向右上倾斜的边界内：

- 两组 HH+HL 仅是候选；至少三组且可画稳定通道线才确认。
- 多头趋势线连接有效波段低点，通道线参考波段高点。
- 初期可用趋势线的平行线，成熟期可用最佳拟合；刺穿后重画必须说明依据。
- 通道宽度取同一时刻上下轨差或明确的垂直间距，不使用依赖图表缩放的角度作为主判据。
- 通道可视为倾斜交易区间或更大结构中的空头旗形，但这只是风险背景，不是必然向下反转。

按最近有效回撤划分窄、常规、宽通道；微型通道是短期高低点连续推进的特例。分类细则见 `channel-width.md`。

## 允许评估的顺势方案

### EMA/趋势线回撤与 H1/H2

1. 回撤接近 EMA、趋势线或前结构支撑，但未破坏关键 HL。
2. 等待已收盘多头信号或其他合规结构。
3. Stop 触发计划在信号棒高点上方一个最小跳动；结构止损通常在信号棒或回撤低点下方。
4. H1 可用于强背景浅回撤；H2 需有两腿证据，但不因 H2 标签提高胜率。
5. 无独立信号棒时可评估 §9.0P 计划型限价，不能绕过方向和结构要求。

### 旗形回撤与突破测试

- 旗形是趋势中的短暂停顿或逆向回撤，需有清晰边界。
- 不在普通第一棒突破追价；优先等回踩、测试成功或失败的失败。
- 计划型限价可位于旗形支撑或顺势回撤位；stop 计划必须位于有效依据 K 线高点外。

### 微型通道

等待第一次逆向突破失败或浅回撤结束后评估做多。第一次突破失败只是可能的延续线索，不是高胜率保证；若突破有跟随并改变结构，应重新诊断。

### 宽通道与台阶

只评估下边界、回撤或突破测试后的做多。上边界不逆势做空；突破上轨不追，等待测试。收缩台阶最后一推不追多。

## 风险与目标

- 止损放在信号棒、回撤或波段失效位外；过宽或处于噪声内时放弃。
- TP1 取最近有效前高、通道近端或结构位；TP2 可取更远通道边界或合规 MM。
- 通道宽度投影必须从突破参考位向多头方向计算，不能把“下轨 + 宽度”误写成突破延伸。
- 每笔都重新执行 §9、§10、§11、§14。

## 失效与禁止

- 跌破关键 HL 或趋势线后需观察收盘、恢复和跟随，不由一根刺穿自动判反转。
- 向下突破、双顶、MTR 和反向信号可写 `reversal_attempt`/`mtr` 与 `watch_points`，但不直接产出逆原趋势做空三价。
- 如果阶段二依 §2.3 合法重判为空头，按新方向和程序校验处理，不能继续套用本文件的做多方案。
- 禁止追高潮、区间中部入场、重复有效方案和违反反手冷却。
- 不写移止损、分批出场、超时平仓或仓位建议。
