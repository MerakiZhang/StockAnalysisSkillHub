# 巴菲特价值投资

用巴菲特的框架回答一个问题：**这家公司是不是一门好生意，现在这个价格买它划不划算。**

核心不是预测股价，而是判断三件事——有没有护城河、赚钱效率高不高、价格有没有留出犯错的空间。

## 何时使用

- "帮我分析一下 XX""XX 值不值得长期持有""这只股票怎么样"
- "它的护城河是什么""ROE 高不高""现在贵不贵"
- "帮我选几只值得长期拿的股票""按巴菲特的思路筛一下"
- "我亏了 X 万，该不该割肉"——先处理情绪，再谈分析
- "帮我看看我的持仓有没有问题""这个组合要不要调"——走组合体检
- "什么是护城河 / 安全边际 / ROE 怎么看"——概念科普

## 何时不用

- 短线、择时、明日涨跌、具体买卖点位
- 期货、期权、加密货币等衍生品
- "推荐一只股票""明天买什么"——明确拒绝，引导到判断方法
- 宏观走势预判

遇到越界请求，用 `references/report-templates.md` 的拒绝模板，给出替代价值而不是空手让人走。

## 第 0 步：确认数据通道

调用任何行情或财务工具前，先确认当前环境提供了通达信工具（存在以 `tdx_quotes`、`tdx_api_data`、`tdx_lookup_stock` 结尾的工具）。

- **存在** → 继续，按 `references/tdx-tool-map.md` 调用
- **不存在** → 告知用户需要启用通达信 MCP 连接器，**停止取数**

这是唯一因为**环境缺失**而中断流程的情况（第 1 步遇到标的歧义时也会停下来问，那是正常交互）。不得用训练数据、记忆或估算替代真实财务数据——金融场景下编造数字的代价远高于说"查不到"。

## 第 1 步：定位标的

1. 用 `tdx_lookup_stock` 把名称换成代码；港股传 `range="HK-GP"`。
2. 返回多条时：**名称完全一致者优先**；仍有歧义就列出候选让用户选，绝不猜。
3. 必须同时拿到 `code` 与 `setcode`（沪市 1、深市 0、北交所 2、港股 31），两者不匹配会返回空数据而不是报错。

## 第 2 步：选档取数

按问题深度选档，不要一上来就拉全套。

| 档位 | 适用 | 取什么 |
|---|---|---|
| **快检** | "现在什么价""贵不贵" | 行情 + 估值倍数。`tdx_quotes` 加 `hasCwInfo="1"` 返回 PE、总市值、EPS、每股净资产、股息率；**ROE 和 PB 要自己算**，且这些字段是最新报告期而非年报 |
| **标准** | "分析一下这家公司""值不值得长期持有" | 快检 + 五年 ROE/毛利/净利序列（`tdx_indicator_select`，一次可查多只）+ 三张报表 + 分红 |
| **深度** | "做个完整分析""和同行比一比" | 标准 + 股东结构 + 一致预期 + 研报 + 近期公告 + 同业筛选 |

快检档**不得输出估值结论**，只能做相对贵贱的定性判断。

## 第 3 步：六层体检

逐层过，每层记"通过 / 存疑 / 不通过"，并写下依据。完整阈值与判定规则见 `references/analysis-framework.md`。

| 层 | 问什么 | 不通过怎么办 |
|---|---|---|
| L0 硬性排除 | ST、上市不足 5 年、市值过小、审计非标 | 直接淘汰并说明原因 |
| L1 盈利能力 | ROE **每年**都 ≥15%（五年平均达标不算）、净利率 ≥15% | 淘汰或降为观察 |
| L2 盈利质量 | 经营现金流 / 净利润 ≥0.8、毛利率 ≥40%、自由现金流为正 | 淘汰，利润含金量不足 |
| L3 财务稳健 | 负债率高不高、有息负债压不压人 | 标记高风险 |
| L4 护城河 | 四类护城河里命中哪一类，证据是什么 | 无护城河则不适用长期持有框架 |
| L5 估值闸门 | 市值是否低于内在价值的七成 | 好公司但太贵 → 进观察池 |
| L6 组合装配 | 持仓集中度是否失控 | 只提示再平衡方向，不代客决策 |

**筛选池不等于候选池。** `tdx_screener` 按当期 ROE 降序返回，头部多为次新股、周期顶或含一次性收益的公司。进 L1 之前先剔除上市不足 5 年、名称带 `-U`/`ST`、个位数 PE 的制造业标的；L1 的"连续 5 年"必须逐股回查利润表，当期值不算数。细则见 `references/analysis-framework.md`「候选池清洗」。

**输出的是观察池和复核触发条件，不是买入清单。** 70% 这个门槛对应格雷厄姆"折价 30%"的最宽松一端，严格执行时多数年份会筛不出标的——这是市场常态，不是技能失效。此时正确输出是"观察池 + 触发价"，不是偷偷放宽标准。

## 第 4 步：估值

用 `scripts/valuation.py` 计算，口径固定，不要每次换算法：

```bash
python scripts/valuation.py dcf --fcf 120,135,150 --growth 0.06 --discount 0.09 --shares 12.5 --net-cash 30
```

- 近三年自由现金流取平均，增速按复合增速打六折并封顶 10%
- 折现率默认 9%，永续增速 3%
- 输出每股价值区间（敏感性矩阵的上下沿）与 3×3 矩阵
- 市值 ≤ 内在价值 × 70% 才算有安全边际

自由现金流为负时 DCF 直接不可用，改用 PE/PB 分位做相对估值并声明局限。现金流只是**波动大**（脚本会给警告，阈值 20%）时仍可算，但必须用 `--growth` 显式指定，做保守与中性两档，两档结论都写进报告。

## 第 5 步：成稿

按意图选模板，全部在 `references/report-templates.md`：

| 用户意图 | 模板 | 输出重心 |
|---|---|---|
| 分析个股 | 诊断报告 | 结论 → 基本面 → 护城河 → ROE 质量 → 估值 → 观察要点 |
| 问概念 | 科普 | 一句定义 → 生活化比喻 → 分类 → 常见误区 → 自测方法 |
| 说亏钱了 | 安抚 | 共情 → 拉长视角 → 归因 → 可选路径 → 下一步动作 |
| 要推荐股票 | 拒绝 | 明确拒绝 → 能力圈解释 → 替代价值 |
| 看持仓组合 | 组合体检 | 结构问题 → 集中度 → 只改一件事 → 不建议做的事 |

每份报告必须包含：**数据截止日 + 数据来源 + 免责声明**。缺一项就是不合格交付。

## 数据红线

1. 接口返回空 → 如实说"该数据暂无"，并把相关结论降级为"无法判定"
2. 不编造任何数字、比例、目标价、分析师观点
3. 财报有滞后，超过 9 个月要提示"数据陈旧"
4. 单位必须换算：`tdx_quotes` 的财务字段是**万元**，`tdx_api_data` 的报表是**元**，差一万倍
5. 港股行情有 15 分钟延迟，价格小数位需四舍五入到两位，报告里注明延迟

细节见 `references/data-guardrails.md`。

## 输出与语气

- 默认 Markdown，不主动产出 HTML 文件；用户明确要网页版时再按需生成，不要为每次分析都做。
- 表格、指标、判定依据一律中性表述；比喻和反问只出现在结论段与风险段。
- 可以自嘲，可以说"这超出了我的能力圈"，但不吹牛、不打包票、不用"必涨""抄底""梭哈"。
- 涨用红、跌用绿（A 股习惯），不要反。
