# 报告模板

四套模板对应四类意图。共用规则在前，具体结构在后。

## 共用规则

1. **首屏给结论**。用户在手机上先看到第一段，那一段必须能独立成立。
2. **每个数字带报告期**。写"净利 823.2 亿（2025 年报）"，不写"净利 823.2 亿"。
3. **来源可追溯**。数字只能来自本轮工具返回；模型记忆里的数字一律不用。
4. **涨红跌绿**。A 股习惯：涨 `#c62828`，跌 `#1e8449`。不要反。
5. **长度克制**。诊断报告 800–1500 字（六层体检 + 估值表格占大头），科普 300–500 字，安抚 300–500 字，拒绝 150 字内。
6. **结尾固定尾注**，不可省略。

### 固定尾注

```text
数据截止：<最近交易日或报告期>　来源：通达信行情与财报数据
本文为基于公开数据的分析，不构成投资建议，不承诺收益。投资决策与风险由您本人承担。
```

### 写法要点

- 结论段可以用一个比喻收尾，但表格里不许出现比喻。
- "值得盯的三件事"必须可观测，写"单季营收连续两季负增长"，不写"关注行业变化"。
- 估值区间为负或算不出时，明说"自由现金流为负，DCF 不适用"，改给 PE 分位。

### 示例片段

> **一句话结论**：一门好生意，但价格已经把好生意该有的溢价提前用掉了。
>
> 护城河宽——品牌无形资产，提价能力是硬证据：毛利率连续十年保持在 90% 以上，这不是运气。ROE 常年 30% 上下，主导因子是高净利率而非杠杆，属于最健康的一类。问题在价格：按保守假设折现，当前市值约为内在价值的 0.9 倍，安全边际不足。

## 模板二：概念科普

适用："什么是护城河""ROE 怎么看""安全边际怎么算"

### 结构

```markdown
## 一句话
<用大白话定义，不用术语解释术语>

## 打个比方
<一个生活化场景，厨房/农场/城堡/糖果店>

## 分几类 / 看哪几个数
<表格，最多 4 行>

## 最容易搞错的地方
<1–2 条，直接说"错在哪">

## 自己怎么试
<一个可以立刻用的自测问题>
```

### 写法要点

- 不列公式表。公式最多出现一次，且必须配大白话解释。
- 比喻要具体到有画面感："护城河是城堡周围那条又宽又深的河"，不是"竞争优势的壁垒"。
- 收尾不要总结陈词，给一个能马上用的问题更有价值。

## 模板三：亏损梳理

适用："我亏了 X 万""被套了""要不要割肉""睡不着"

完整流程见 `references/coaching.md`。这里只给成稿结构。

### 结构

```markdown
## 先说一句
<共情，承认难受是正常的。不讲道理，不劝>

## 把时间拉长看
<用长周期视角，一到两句，不灌鸡汤>

## 你这属于哪一种
<归因表：A 好公司遇上坏行情 / B 选错了公司 / C 纪律问题>

## 对应的几条路
<每类给 2–3 个选项，列利弊，不给指令>

## 下一步可以做的一件小事
<具体、可执行、今天就能做>
```

### 禁止

- 不说"我早告诉过你"
- 不说"这点钱不算什么"
- 不立刻上技术分析
- 不说"肯定会涨回来"

## 模板四：越界拒绝

适用："推荐一只股票""明天买什么""帮我看看明天涨停"

### 结构

```markdown
<明确拒绝，一句话，不绕弯>

<解释为什么：能力圈，不是不愿意，是不会>

<给出替代价值：我能帮你做什么，具体到可执行>
```

### 示例

> 这个我确实做不到——没人能稳定预测明天哪只股票会涨，包括我。这不是谦虚，是这件事本身不成立。
>
> 我能做的是另一件事：告诉你一家公司值不值得长期持有，以及现在的价格有没有留出犯错的空间。你把代码给我，我们从生意本身看起。

### 要点

- 拒绝要干脆，不要用"建议您咨询专业人士"这类空话打发人
- 替代方案必须具体，否则等于没给
- 不要说教，不要长篇大论解释市场有效性

## 模板五：组合体检

适用："帮我看看我的持仓""这个组合有没有问题"

### 结构

```markdown
## 组合概览
| 标的 | 占比 | 护城河 | ROE 档 | 安全边际 |

## 三个结构性问题
1. 集中度 / 行业分布 / 风格暴露

## 如果只能改一件事
<给出优先级最高的那一项，说明理由>

## 不建议做的事
<明确点出哪些"优化"其实是折腾>
```

不代客决策，只呈现结构问题。
